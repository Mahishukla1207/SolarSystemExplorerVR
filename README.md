# 🌌 Solar System Explorer VR

An interactive Virtual Reality experience that allows users to explore, observe, and learn about the Solar System through immersive VR environments.

Built with Unity 6, Blender, and the XR Interaction Toolkit, the project combines simulation, exploration, and educational elements into an interactive VR experience.

## 🚀 Project Overview

Solar System Explorer VR was developed to create an immersive and educational way of experiencing the Solar System.

The experience begins inside a futuristic Mission Control room, from which the user can choose between two different modes:

### 🌍 Exploration Mode

Exploration Mode allows users to observe the Sun and planets closely.

Each celestial body rotates on its axis and is accompanied by an information panel containing educational facts and planetary data.

Users can explore:

- Sun
- Mercury
- Venus
- Earth
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune
- Pluto

A VR portal allows the player to return to Mission Control.

### 🪐 Simulation Mode

Simulation Mode demonstrates the movement of the Solar System.

The planets:

- Rotate on their own axes
- Revolve around the Sun
- Follow individually created orbital paths

This mode provides a visual representation of planetary motion in an immersive VR environment.

## ✨ Key Features

- Immersive VR Mission Control environment
- Separate Exploration and Simulation modes
- Interactive VR scene navigation
- Planetary rotation
- Planetary revolution around the Sun
- Custom orbital systems
- Educational information panels
- VR controller interaction using XR Interaction Toolkit
- Scene transitions through interactive buttons
- Portal-based navigation
- Emission-based futuristic lighting
- Space-themed environment and skybox
- Custom planet assets created using Blender
- Tested in VR using Meta Quest

## 🛠️ Technologies Used

- Unity 6
- C#
- Blender
- XR Interaction Toolkit
- OpenXR
- Universal Render Pipeline (URP)
- Meta Quest

## 🎮 Project Flow

Mission Control

→ Exploration Mode  
→ Observe planets and read educational information  
→ Return to Mission Control through the portal

or

Mission Control

→ Simulation Mode  
→ Observe planetary rotation and revolution  
→ Return to Mission Control through the terminal
